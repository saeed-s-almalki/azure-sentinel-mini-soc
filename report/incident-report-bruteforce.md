## 1. Executive summary
Microsoft Sentinel detected a burst of failed logon attempts (Windows Security **EventID 4625**) targeting the domain member server **RTS-SVR1**. Twenty failed attempts originated from a single source against ten distinct usernames within a short window — a classic brute-force / password-spray pattern. The activity was a **controlled attack simulation** performed as part of this lab; the detection, alert, and incident all worked as designed, so the alert is a **true positive** with a benign root cause.

## 2. Detection
- **Analytics rule:** `Windows - Failed logon brute force (4625)` — Sentinel **Scheduled** query rule (deployed as code: `deploy/analytics-rule-bruteforce.json`).
- **Data source:** `SecurityEvent` table — Windows Security Events collected via the **Azure Monitor Agent (AMA)** and a **Data Collection Rule (DCR)** from an **Azure Arc**-enabled server.
- **Trigger:** ≥ 10 failed logons (EventID 4625) from the same source IP against a host, evaluated every 5 minutes over a 1-hour lookback. Creates an incident on match.

## 6. Findings
The alert is a **true positive** for the detection logic: the query correctly identified a brute-force pattern (20 failures / 10 accounts / 1 source in minutes). Root cause is a **planned lab simulation**, so there is no real compromise — but the same signal from an untrusted external IP would be a genuine credential-access attempt and should be escalated.

## 7. Recommendations
- Enforce an **account lockout policy** (e.g., lockout after N failed attempts) to blunt brute force.
- Require **MFA** for interactive and remote logons.
- **Block / rate-limit** repeat offender source IPs at the firewall; disable unused local accounts.
- Tune the rule: raise severity and auto-assign when the **source IP is external** (not loopback/RFC1918).
- Continue monitoring 4625 spikes per source/host and correlate with 4624 (successful logon) to catch a successful guess after many failures.

## 8. Appendix — KQL used
```kql
// Verify ingestion
SecurityEvent
| summarize Count = count() by EventID
| order by Count desc

// Brute-force detection (T1110)
SecurityEvent
| where EventID == 4625
| summarize FailedAttempts = count(),
            Accounts = make_set(Account, 20),
            StartTimeUtc = min(TimeGenerated),
            EndTimeUtc = max(TimeGenerated)
    by IpAddress = tostring(IpAddress), Computer
| where FailedAttempts >= 10
| order by FailedAttempts desc
```
